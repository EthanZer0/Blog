有些时刻并不盛大，却值得记下来。清晨窗边的一束光，散步时吹来的风，和一本读到一半的书，都可以成为文字的起点。

这个小站，是留给这些时刻的一张白纸。

## 从一个小小的念头开始

写作不必总是先有一个完整的答案。把正在想的事情写下来，思路就会慢慢清晰起来。

**认真生活，也认真表达。** 我喜欢文字里恰到好处的留白，喜欢一段话读完之后，还有一点余韵。

> 我们记录时间，也在时间里认识自己。

### 阅读时的节奏

段落之间需要呼吸，标题与正文之间需要距离。一个舒适的阅读页面，应该让你自然地把注意力放在文字上。

- 留出适当的行距。
- 让长段落保持清晰的结构。
- 用图片和引用补充表达。

## 代码与思考

偶尔也会在这里分享技术笔记。下面是一个简单的 TypeScript 示例：

```typescript
interface Moment {
  title: string;
  date: Date;
}

const moments: Moment[] = [
  { title: '一个值得记录的清晨', date: new Date('2026-10-06') },
];

for (const moment of moments) {
  console.log(moment.title);
}
```

行内代码，比如 `const` 和 `Date`，也应该融入段落，不打断阅读。

### 一点数学

有时，一个公式可以让想法更准确。比如 $a^2 + b^2 = c^2$，或者：

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
