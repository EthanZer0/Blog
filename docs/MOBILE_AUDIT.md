# 手机端功能检查（2026-10-08，仅本地）

本次以本地生产预览和 Chromium 触摸模拟检查交互，使用 390×844 及 320×740 视口；未进行截图或视觉对照，未推送、未部署。

## 检查范围

- 17 个实际 HTML 页面：首页、文稿列表与两篇正文、两篇手记、分类页、两类标签页、时间线、空专栏列表、搜索、关于、404。三条手记旧地址为重定向页，由静态路由验证覆盖。
- 各页触摸纵向滚动、水平溢出；五个导航栏目、时间线子菜单、前进/后退；搜索弹窗和搜索页的结果、清除、重复进入及链接跳转。
- 文稿显示设置：排序、升降序、紧凑/预览模式，Select 选项点按与关闭，浮层外部点按、打开浮层后换页，滚动到页脚后的按钮可点按。
- 标签云、嵌套标签弹窗及链接跳转；文章目录锚点和关闭后滚动；手记字体选择、保存、跨手记恢复、关闭及换页；亮色/暗色/跟随系统按钮和跨页恢复。
- 正文折叠内容、复制代码、手机图片查看及点按关闭、分享弹窗与复制链接；首页时间轴详情抽屉、正文链接及换页清理。

## 已修复

1. 持久化导航与 body Portal 生命周期不一致，导致菜单关闭动画中换页后遗留触摸拦截。菜单、搜索与共享 Modal 在 body 替换前同步关闭并卸载弹层；正常关闭时仍保留原动画。
2. FloatPopover 的通用外部点按监听误用于手机 Drawer 分支，因该分支未设置浮层引用，内部点按也会被误判为外部。手机抽屉现在交由 Vaul 自身处理外部点按，并在换页前同步清理。
3. 文稿设置、目录、字形 FAB 原先困在正文的 stacking context 中，页脚可遮挡按钮。沿用上游 FAB 的 RootPortal 方式挂载到 body。
4. FloatPanel 原先将外部关闭逻辑注释掉，缺少 Escape 和换页清理，位置也不随滚动更新。恢复这些行为，Select 列表的内部点按不触发误关闭。
5. 320px 浮层宽度及横向位置超出视口。限制浮层宽高，允许内容内部滚动，并对 Floating UI 开启带 16px 边距的横向位置约束。
6. 独立搜索页脚本原先只在首次进入初始化。改为 astro:page-load 初始化、astro:before-swap 销毁，异步加载完成时确认页面仍有效，重复进入复用已加载的 Pagefind UI。
7. 代码复制按钮原先依赖鼠标 hover，在触摸设备上不可见。触摸设备常显，保留鼠标悬停显示方式；复制与展开按钮添加可访问名称。
8. 时间进度原先误将动画时长 2 秒直接作为 setInterval 的 2 毫秒，且使用两个计时器。合并为一个 1000ms 计时器，原 2 秒数字动画保持不变。

## 验证与边界

以上实际页面及按钮的集中功能检查通过，没有页面脚本错误。类型检查、静态构建/路由/资产验证和上游样式审计通过。

触摸模拟不等同于真实 iOS Safari 或 Android 浏览器验收。系统原生分享、第三方分享网站、字体 CDN 网络可用性及剪贴板权限由设备和浏览器决定；本次验证本地复制成功与分享回退面板。当前公开文章未包含视频、Tabs 或多图 Gallery 示例，这些渲染器已做源码与现有静态语法检查，未宣称完成手机媒体播放、原生全屏及多图手势实机测试。
