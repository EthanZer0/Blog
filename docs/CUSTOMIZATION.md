# Blog 定制记录

个人定制仅在 Blog 维护，不自动同步至 Shiro-For-Astro。

## 文章页尾与 Footer

文章页尾采用标题/作者/日期、网址与复制按钮、许可声明三行结构；修改时间晚于发布时间时优先显示修改日期。正文与页尾增加留白，使用暖灰色。

Footer 使用淡黄色渐变，名字与斜体签名使用衬线字体；版权和技术署名、淡分割线、竖线分隔的链接、右下角原主题切换按钮依次排列。

## 时光页（2026-10-10）

顶部为小标题、文章总数、并列迷你翻页计数及寄语。进度按访客本地时间计算；今年第几天考虑闰年，年度百分比取整数，今日百分比保留三位小数，按当地相邻午夜计算一天长度。每秒检查数值，后台页停止周期更新，返回前台立即刷新；仅变化数字翻页，减少动态偏好下即时完成。

文章日期以 Asia/Shanghai 按年/月倒序分组，月标题显示中文与英文缩写。列表仅有浅灰元信息与深色标题两种文字色，暗色主题相应适配。分类来自 Markdown category，类型显示文稿/手记。

全量静态列表无分页，使用共用的列表入场机制，按可见批次逐项柔和展开，滚动进入视口的条目继续展开；Astro 路由切换清理观察器与动画。保留 type/year 查询筛选，筛选后同步隐藏空月份与年份、更新篇数。

时光页字体采用已有 Noto Serif SC 宋体风格字体栈，中文标题、年月和元信息统一衬线风格，适量增加字距；文章标题使用常规字重和 1.9 行高，英文月份缩写用正体。日期及翻页数字使用系统等宽字体，保留数字对齐，不新增字体下载。

## 极简搜索卡片（2026-10-10）

遮罩亮色透明度 .04、暗色 .12，模糊 1px；桌面面板最大 600×440px，平板/手机最大 560×420px，手机两侧各 16px，保留可视区及键盘安全范围适配。输入区融入毛玻璃背景，无独立边框或底色，提示为“搜索...”，中央提示使用浅色衬线斜体。取消关闭按钮，通过外部点击或 Esc 关闭，输入法组合期间保留 Esc 保护。浅色分隔线自中心向两侧淡至透明，保留搜索清空及键盘选取。入场为 180ms ease-out、退出 160ms，位移 8px、缩放 .985。

搜索 Portal 存在期间强制 root 显示滚动条，并取消该弹窗的重复 body 右边距及导航补偿；保留 Radix 背景滚动锁。CSS 通过实际面板存在状态控制，覆盖退出动画直至卸载，无额外全局状态或计时器。

## 首页中部（2026-10-10）

首页 Hero 与年度时间线保留，中部重构为“近期 / 最近的事”。近期合并文稿与手记，按有效修改日期或发布日期倒序，最多显示十篇；序号 01 起，序号之间的细线连续渐淡至透明。每条包含标题、紧密圆点分隔的分类与类型，以及右侧日期；全部入口跳转至时光页。

最近的事使用现有静态发布/修改记录，每条为浅色左边线文本块，底部显示上海时区日期时间，无原图标和绿色纵轴，保留可滚动区域。两栏在桌面以浅色细线分隔、顶部对齐，手机上下排列；统一使用已有宋体风格字体和暖灰色，不新增字体资源。

近期日期按上海时区的日历日分级：当天“今天”、前一天“昨天”、2–29 天“x天前”、30 天及以上 YYYY/MM/DD；未来时间使用完整日期。悬停显示发布/最后修改的完整日期时间，客户端随页面生命周期持续刷新，静态 HTML 也包含构建时的相应标签。



## 首页年度时间轴（2026-10-10）

标题改为宋体斜体‘时间...’，轴线、节点与文章标记统一暖灰淡金色，暗色主题同步适配。整块时间轴以 450ms 快速横向展开，所有节点及柱条随展开同步出现，移除原 3 秒展开及逐个下落动画；减少动态偏好下直接显示。柱条采用细窄渐变和圆角顶端，月份标注以浅色小年份搭配稍大的中文月份（一月至十二月），上下居中排列，避免长月份与相邻标签拥挤。保留近十二个月、月份发布总数及文章入口弹层，手机端默认定位最近月份，日期统一按上海时区分组。



首页底部导航去掉‘风向标’标题，以‘去到别处看看？’作为唯一标题，与‘时间...’共用宋体斜体、字号、字距和暖灰色样式。文稿、手记等入口去掉图标，保留链接、分隔圆点及既有交互动画。


底部导航入口 hover 采用暖金色文字与从中心展开的浅渐变细线，取消旧绿色强调及上跳；颜色 180ms、细线展开 220ms，共用 ease-out 曲线。亮暗主题分别配色，保留键盘 focus-visible 提示与 44px 点击高度，触摸设备只显示按压反馈，减少动态偏好下取消过渡。


首页中部字体层级改为深暖灰板块标题、次深色文章标题、中灰动态叙述、浅灰分类/日期/序号，暗色主题对应反向亮度层级。标题略增字重，序号使用轻斜体，保持原字号和布局。文章链接悬停改为暖金色文字，不再通过降透明度削弱标题，保留键盘焦点提示。


## 导航栏配色（2026-10-10）

导航局部强调色改为暖金 #987a45，暗色为浅金 #d1ba88；主/浮动导航、选中图标与渐变下划线、跟随光晕、下拉菜单、手机导航及顶部搜索触发按钮使用统一配色。卡片使用淡米黄玻璃背景及暖灰边缘，手机抽屉同步暖色背景。通过导航局部 CSS 变量覆盖强调色，Portal 菜单单独继承同一套配色，不影响正文等其他区域的全局强调色及原有切换动画。


## 整站切页动画（2026-10-10）

正文与 Footer 作为独立 page-content 过渡区域，原页面 80ms 淡出并微微上移，新页面延迟 80ms 后以 340ms 淡入、12px 位移与轻微缩放展开，末段带 1px / .1% 的克制弹性回落。前进后退使用同一动画；原生切页中淡出结束后才启动淡入，消除两页文字重叠。导航栏及背景保持持久化独立层，路由期间取消 root 的窗帘裁切及尺寸插值；主题切换仍使用原 root 效果。动画通过 Astro transition:animate 配置生成，原生 View Transitions 与非原生回退都适用，减少动态偏好下即时完成。不增加路由计时器或新的滚动锁。


## 列表逐项入场（2026-10-10）

文稿列表与时光页的年份、月份和文章行共用 420ms 淡入舒展动画，18px 上浮后轻微回落。视口内每批按文档顺序以 45ms 间隔依次展开，最大延迟 180ms；长列表按滚动进入视口继续展现，不累积整页延迟。独立 translate 属性避免覆盖文章磁吸 hover 的 transform。首屏及 Astro DOM 交换前设置渐进增强标记，避免已显示内容再突然隐藏；不启用 JS、减少动态及打印时直接显示。键盘聚焦立即显示对应条目，路由切换清理观察器及动画，筛选仍在入场观察前完成。

时光页时间进度恢复为静态数字卡片：移除整组入场、数字翻页及快速翻页序列，清理动画状态、队列、起步计时器和对应 CSS。保留卡片外观、今年第几天、今年进度及今日进度（三位小数），每秒直接更新真实数值，页面返回前台时立即刷新；卸载时清理更新计时器及事件。
