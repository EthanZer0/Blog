## 当前交付范围

静态内容与路由、首页 Hero/最近文章/最近手记/动态/年度时间线、胶囊导航、文稿列表、手记列表与纸张阅读布局、正文、目录、主题切换、搜索、RSS、Sitemap、GitHub Actions。

已完成迁移基础及第二轮首页/阅读页源码校准，不能视为已经完成像素级验收。作者个人资料使用明确的演示占位信息；不会冒用 Innei 的文章、签名或社交账号。

## 当前阶段内检查

- `npm run check`：Astro / TypeScript。
- `npm run build`：静态页面 + Pagefind。
- `npm run verify`：产物内链接/锚点、资源、草稿隔离、RSS、索引和后端依赖。
- 子路径部署单独构建检查。
- 构建前强制同步内容，避免修改 Markdown 插件后复用旧渲染缓存。
- 关键页面集中检查浏览器，不为每次小修改重复截图。

## 第二轮视觉校准（已完成）

- Hero 恢复分组入场、品牌色社交按钮及原按压缩放参数。

- 文稿列表恢复原磁吸悬停参数，目录恢复章节线、圆环进度与回到顶部。
- 手记与文稿分开布局：手记恢复 60rem 纸张、左对齐标题和 xl 侧栏；文稿恢复手机 px-2。
- 年度时间线恢复原几何标记，使用上海时区，手机默认滚到最新月份。
- 当场修复手机纸张宽度与负边距冲突；为 1024–1279px 手记保留可展开目录。
- 剩余视觉差异详见 SOURCES.md，手机抽屉和浮动目录优先进入下一轮。
