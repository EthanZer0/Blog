# Shiro → Astro

## 固定参考

- 上游：https://github.com/Innei/Shiro
- 提交：`891bb24cd59aff7c9baaf4d9a3579ca4275da3b7`
- 原则：复用原布局、样式与 Spring 参数，不另行设计视觉风格。
- 用户要求：问题在当前阶段修复；减少浏览器视觉检查；必要时请求用户辅助。

## 当前交付范围

静态内容与路由、首页 Hero/最近文章/最近手记/动态/年度时间线、胶囊导航、文稿列表、手记列表与纸张阅读布局、正文、目录、主题切换、搜索、RSS、Sitemap、GitHub Actions。

本轮是可运行的迁移基础，不能视为已经完成像素级验收。作者个人资料使用明确的演示占位信息；不会冒用 Innei 的文章、签名或社交账号。

## 当前阶段内检查

- `npm run check`：Astro / TypeScript。
- `npm run build`：静态页面 + Pagefind。
- `npm run verify`：产物内链接/锚点、资源、草稿隔离、RSS、索引和后端依赖。
- 子路径部署单独构建检查。
- 构建前强制同步内容，避免修改 Markdown 插件后复用旧渲染缓存。
- 关键页面集中检查浏览器，不为每次小修改重复截图。

## 后续范围

- 首页与正文针对固定参考截图做细节校准。
- 增加完整扩展语法兼容：Spoiler、Tabs、LinkCard 等。当前仅明确支持普通 Markdown、公式、提示容器与画廊容器，未知容器在构建时报告错误。
- 视需要添加思考、项目、友链、系列。

## 永久移除

Mix Space API、Next 服务端、后台、身份认证、评论计数、在线人数、实时推送、活动上报、阅读与点赞计数。动态流从公开文章数据生成，无模拟实时状态。
