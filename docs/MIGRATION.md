## 阅读设置阶段（2026-10-07）

- 依据原 NoteFontFab 接入手记字形面板，仅在手记显示。面板尺寸、四个原字形预览、选中环、浮动按钮尺寸与动效保留。
- 支持默认衬线、无衬线、霞鹜文楷、悠哉；沿用 `note-font` 本地偏好键、字体栈与上游 CDN 地址，持久化输入验证并容错。
- Astro 切页移除外部字体 link 后，在再次进入手记时按当前 DOM 重载，不缓存已脱离文档的 link。
- 字形和目录入口共用浮动容器，避免重叠；手记的可展开目录在 1280px 以下可用，与桌面侧栏的显示断点衔接。
- 原码没有通用的字号、行距调整面板，没有自行添加此类视觉控件。

## 分享与沉浸阅读阶段（2026-10-07）

- 分享入口采用原 Post/NoteActionAside 的图标、按钮、侧栏位置、正文末尾显现和页尾旋转；窄屏置于正文下方。手记中间宽度的入口沿用本站 xl 侧栏断点，避免入口缺失。
- 原生 `navigator.share` 优先；用户取消不弹出第二个分享界面，其他失败回退至原 ShareModal 布局、二维码、Twitter、Telegram 与复制链接。原平台 SVG 完整复用并纳入源码审计。
- 平台 URL 参数编码，复制成功提示仅在写入成功后显示；分享 URL 使用当前站点 origin 与构建时静态路径，保留 Pages 子路径并排除目录锚点与查询参数。
- 复用现有模态栈，分享启用原点击外部关闭行为。479px 以下分享内容改为单列，修复原固定双列在窄屏的溢出；桌面保留 200px 二维码与原双列尺寸。
- 原 ImmersiveReadingInteractionProvider 和 TocAside 行为接入文稿与自定义关于页：300ms 鼠标矩形检测，目录在正文内淡至 0.2、禁用指针，移出恢复 1；保留原 smooth Spring 参数。手记保持原不启用行为，没有另加阅读模式开关。
- Astro 切页清理节流、监听及动画；减少动态偏好时取消弹簧动画。集中验证系统分享成功/取消/失败、二维码/复制/编码、切页及 390/1100/1440px 入口与面板。
